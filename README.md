# ✦ ATELIER ROUGE — Cinematic Blooming Rose

A high-end, cinematic, single-page interactive luxury experience. Designed with a **deep velvet & obsidian aesthetic**, featuring a pure procedural blooming crimson rose, 3D parallax physics, falling rose petals with depth-of-field simulation, an animated multilingual greeting, and an ambient Web Audio soundscape.

---

## ✨ Features

- 🌹 **Pure Blooming Rose (No Hand)**:
  - Grand entrance choreography unfolding petals smoothly on initial load.
  - Layered velvet gradients (`#ff1a40` highlights to `#250208` deep shadow folds), natural botanical stem, emerald leaves, and crystal dewdrops with light pings.
  - Interactive 3D parallax mapped to mouse movement and mobile gyroscope tilt.
  - Touch-to-bloom with sparkle bursts and crystalline harmonic audio chimes.

- 🌍 **Multilingual Animated Greeting**:
  - Dynamically cycles every 2.5 seconds through *Hello, Hola, Bonjour, Ciao, Namaste, Konnichiwa, Guten Tag, Olá*.
  - Smooth vertical slide-up and soft Gaussian blur transitions.

- 🍃 **Procedural Falling Rose Petals Canvas**:
  - 3-tier depth of field (far blurred, mid sharp, foreground bokeh).
  - Wind turbulence, natural 3D tumbling, and interactive cursor/touch deflection.

- 🎶 **Web Audio API Velvet Soundscape**:
  - 100% procedural synthesizer: warm low-pass chord drone (A2, E3, A3, C4) + harmonic pentatonic bell chimes.
  - Discreet top-corner audio toggle with live animated equalizer wave bars.

- 📱 **Mobile-First & 100dvh Responsive**:
  - Fluid aspect ratio and `100dvh` lock without unwanted scrollbars or tap bounce.

---

## 🛠 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Audio Engine**: Web Audio API (zero external audio file dependencies)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
git clone https://github.com/ssachatan-alt/insta.git
cd insta
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
